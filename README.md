# GV PORTAL

**GV PORTAL** is an online examination and assessment portal featuring:
- **C Level 2 Assessment**: 56 comprehensive programming questions with in-browser compilation & execution using JSCPP, public/hidden test cases, custom input runner, code editor with syntax autocompletion and bracket matching, timer, score calculation, and level unlocking.
- **C Level 3 Assessment (Arrays)**: 52 array algorithm challenges with automated test case evaluation.
- **IPR Patent Search Assessment**: Multi-section patent search assessment (Sections A–E) referencing Google Patents, Espacenet, and WIPO PATENTSCOPE, with question generators and response saving.

## Getting Started

### Option 1: Open Directly in Any Browser
You can open [index.html](file:///c:/Users/Vivin%20K%20G/G%20V%20Test%20portal/index.html) directly in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Run with Local Node.js Server
Start the built-in HTTP server:
```bash
npm start
# or
node server.js
```
Then navigate to:
**http://localhost:3000**
